# Episode index

Videos link to maintained topic guides. Episode numbers describe viewing order and do not determine folder names. Several episodes can use the same guide.

| Episode | Topic | Video | Guide | Materials | Recording revision |
|---|---|---|---|---|---|
| First episode, number pending | Proxmox on Hetzner | Recording | [Installation guide](../infrastructure/proxmox-hetzner/README.md) | [Not yet added](../infrastructure/proxmox-hetzner/materials/README.md) | Commit or tag not yet recorded |

When publishing an episode, add its number, YouTube link, and the Git commit or tag used in the recording. Link any available documents or slides through the guide's materials index.

The linked guide may change after publication. Check it for corrections before following a recording. Add a dated correction note to the guide when a change affects commands or safety, and link that note from the affected episode entry.
