# Episode index

Videos link to maintained topic guides. Episode numbers give the viewing order and do not determine folder names. Several episodes can use the same guide.

| Episode | Topic | Video | Guide | Materials | Recording revision |
|---|---|---|---|---|---|

When publishing an episode, add its YouTube link and the Git commit or tag used in the recording. Link documents or slides through the guide's materials index.

A guide can change after publication. Check it for corrections before following a recording. When a change affects commands or safety, add a dated correction note to the guide and link it from the episode entry.
