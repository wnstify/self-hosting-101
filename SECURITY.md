# Reporting a security problem

The scripts here run as root and erase disks. If you find a way one of them can
be fooled, or any other security flaw in this repository, report it privately.

Write to security@webnestify.cloud. That mailbox belongs to Webnestify s.r.o.,
which handles security reports for Webnestify Education as well. It is also the
contact in https://webnestify.cloud/.well-known/security.txt.

Do not open a public issue for a security flaw. You will get a reply within
seven days. Include the script or guide, what you did, and what happened; leave
out any of your own addresses, serials, or credentials.
