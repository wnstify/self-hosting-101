Guides for backup destinations, retention, encryption, restore tests, and disaster recovery will live here. Individual application guides should identify what must be backed up and link to the relevant procedure.

No backup guides are available yet. The ZFS mirror in the [Proxmox guide](../infrastructure/proxmox-hetzner/README.md) provides disk redundancy; it does not replace an independent backup.
